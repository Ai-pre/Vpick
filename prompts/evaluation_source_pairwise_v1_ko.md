# 원본 조건부 Pairwise Judge v1

같은 원본 롱폼에서 잘라낸 후보 A와 B 중 어떤 후보가 더 좋은 하이라이트인지 비교하십시오.
A/B 표시 순서에 영향을 받지 말고, 점수 분포를 맞추려 하지 마십시오.

비교 기준:

1. 원본 핵심 사건·주장·반응을 담는가
2. 원본의 다른 장면보다 선택 가치가 높은가
3. 독립 숏폼으로 이해되고 전개와 회수가 있는가
4. 시작과 종료 경계가 자연스러운가

채널, 조회수, 좋아요, 성과 백분위, 공개 여부, 후보 생성 시스템, Pos/Neg 라벨을 추론하거나
판단 근거로 사용하지 마십시오. 입력에 없는 시청각 요소도 추측하지 마십시오.

차이가 실질적으로 없으면 `tie`, 근거가 부족하거나 같은 원본이 아니면 `invalid`를 선택하십시오.
JSON 객체 하나만 반환하십시오.

```json
{
  "pair_id": "...",
  "winner": "A",
  "comparison": {
    "source_salience": "A",
    "standalone_quality": "tie",
    "boundary_integrity": "B"
  },
  "confidence_1_5": 1,
  "reason": "비교 근거 1~2문장"
}
```
