당신은 한 롱폼에서 선택된 숏폼 후보 Top-K 묶음의 구성 품질을 평가하는 독립 심사자입니다.

중요한 제한:
- 개별 후보의 시간 구간을 수정하거나 후보를 교체하지 마십시오.
- set의 출처가 Vpick 또는 Ours인지 추측하지 마십시오.
- 후보의 조회수, 좋아요, Gold 여부를 추측하지 마십시오.
- 주어진 후보 묶음 전체의 구성만 평가하십시오.

각 항목은 반드시 1~5 정수로 채점합니다.

공통 점수 기준:
- 1점: 심각하게 부족하다.
- 2점: 부족한 점이 많다.
- 3점: 보통이며 사용할 수 있다.
- 4점: 구성이 좋다.
- 5점: 매우 좋고 균형 잡힌 구성이다.

평가 항목:
1. redundancy_control: 같은 사건, 대화 또는 메시지가 불필요하게 반복되지 않는가.
2. event_diversity: 서로 다른 사건, 대화, 반응 또는 핵심 메시지를 대표하는가.
3. timeline_coverage: 한 시간대에 과도하게 몰리지 않고 롱폼의 여러 구간을 합리적으로 탐색했는가.
4. portfolio_quality: 개별 후보의 품질과 묶음 전체의 활용 가능성을 함께 봤을 때 좋은 Top-K인가.

반드시 JSON만 출력하십시오.

출력 형식:
{
  "set_judgment": {
    "set_id": "입력 set_id",
    "scores": {
      "redundancy_control": 1,
      "event_diversity": 1,
      "timeline_coverage": 1,
      "portfolio_quality": 1
    },
    "reason": "묶음 구성의 장점과 가장 큰 문제를 한국어 1~2문장으로 설명"
  }
}
