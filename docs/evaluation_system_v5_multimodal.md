# Vpick Gold 멀티모달 평가체계 v5

## 목적

v5는 transcript 품질에 좌우되던 v4의 한계를 줄이기 위해 Gemini가 실제 Gold 영상 구간의 화면과 음성을 직접 보고 쌍대비교하는 자동 Judge다. 새로운 하이라이트를 생성하거나 경계를 수정하지 않고, 이미 고정된 두 후보 중 어느 쪽이 더 좋은 숏폼 구간인지 평가한다.

## 평가 데이터

- 전체 Gold 페어: 45개
- 성과 라벨: Pos 31개, Neg 9개, Unlabeled 5개
- 멀티모달 비교: 같은 채널 Pos-Neg 18쌍
- 고유 후보: 25개
- 고유 원본 YouTube 영상: 20개
- 반복: 비교당 2회, 2회차 좌우 반전
- 모델: Gemini 3.1 Flash-Lite
- 배치: 요청당 4개 비교(영상 구간 8개)
- Gemini 실제 호출 수: 10회
- 실제 판정 행: 36개

20개 원본 영상은 모두 2026-07-21 기준 공개 접근 가능함을 확인했다.

## 블라인드 입력

Gemini에는 다음 정보만 전달한다.

- LEFT와 RIGHT의 공개 YouTube 영상 구간
- 정확한 시작·종료 초
- 익명 candidate ID
- Vpick 장면 설명과 transcript 보조 정보
- 평가 기준과 JSON 출력 형식

다음 정보는 전달하지 않는다.

- Pos/Neg 라벨
- 조회수와 좋아요
- Vpick/Ours 시스템 이름
- Gold pair ID
- 성과 백분위

YouTube 영상 자체에서 프로그램이나 인물을 알아볼 가능성은 있으므로, 프롬프트에서 기억에 의한 게시 성과 추측을 금지한다.

## 멀티모달 근거

Judge는 transcript보다 다음 실제 관측을 우선한다.

- 표정과 인물 간 반응
- 행동과 사건 변화
- 화면 자막과 시각적 정보
- 발화 내용, 억양, 웃음, 침묵, 음향
- 영상 첫 프레임과 마지막 프레임의 경계 자연스러움

영상이나 음성을 확인하지 못하면 낮은 점수를 주지 않고 `abstain`한다. 기본 샘플링은 2 FPS이며, 빠른 반응을 1 FPS보다 더 안정적으로 관찰하기 위한 설정이다. 무료 API 요청 제한을 지키기 위해 4개 비교를 한 요청으로 묶고 요청 사이에 65초를 둔다.

## 평가 기준

v4와 동일하게 두 축을 분리한다.

### 편집 구간 품질

- 상황·논점 명확성 15%
- 사건·대화·주장 진행성 15%
- setup-payoff·결론 완결성 25%
- 시작·종료 경계 자연스러움 20%
- 콘텐츠 밀도 15%
- 독립 이해 가능성 10%

### 내재적 성과 잠재력

- 감정·반응 강도 20%
- 갈등·반전·발견·변화 20%
- 구체성·새로움 20%
- 공감·논쟁·공유 가능성 15%
- payoff 강도 15%
- 훅·제목화 가능성 10%

## 타당성 게이트

- 영상 평가 커버리지 >= 0.80
- 좌우 반전 편집 판단 일치도 >= 0.80
- 좌우 반전 성과 판단 일치도 >= 0.80
- 사람 평가 3명 x 18쌍 완성률 = 1.00
- 인간 다수결과 Gemini 일치율 >= 0.70
- 인간 평가자 간 Fleiss' kappa >= 0.40

조회수 Pos 선호 정확도 >= 0.65는 외부 성과 정합성 진단이며 콘텐츠 Judge의 필수 타당성 조건이 아니다.

## 같은 Gemini 계열 사용에 대한 통제

Vpick의 하이라이트 선택에도 Gemini가 사용된 것으로 알려져 있으므로 v5는 완전히 독립적인 모델 Judge가 아니다. 이를 다음과 같이 통제한다.

1. Gemini는 후보의 출처와 성과 라벨을 모르는 블라인드 상태로 평가한다.
2. 동일 비교를 좌우 반전해 위치 편향을 측정한다.
3. Terra와 Claude의 기존 텍스트 판정을 독립 보조 결과로 함께 보고한다.
4. 최종 유효성은 실제 영상을 본 3인 인간 평가와의 일치도로 결정한다.

## 실제 검증 결과

2026-07-21에 18쌍을 좌우 반전해 2회씩 평가했다.

| 지표 | Gemini 멀티모달 | Terra 텍스트 | Claude 텍스트 |
|---|---:|---:|---:|
| 평가 커버리지 | 1.0000 | 0.8889 | 1.0000 |
| 편집 판단 반복 일치도 | 0.5000 | 0.8750 | 0.8235 |
| 성과 판단 반복 일치도 | 0.6111 | 0.8750 | 0.7647 |
| Pos 엄격 선호 정확도 | 0.3889 | 0.4375 | 0.2778 |
| 결정된 비교의 Pos 정확도 | 0.6364 | 0.5000 | 0.3571 |
| 평균 자기 신뢰도(5점) | 4.6667 | 3.7812 | 3.5000 |

Gemini는 36건을 모두 평가했지만 반복 신뢰도 게이트 0.80을 통과하지 못했다. 편집 판단은 18쌍 중 9쌍, 성과 판단은 7쌍이 좌우 반전 후 달라졌다. 이 중 같은 화면 위치만 반복 선택한 경우가 편집 4쌍, 성과 5쌍으로 위치 편향도 관측됐다.

점수 포화도 확인됐다. 편집 세부 점수의 83.3%가 4점 이상이었고 좌우 편집 총점 평균은 각각 84.76점과 84.44점이었다. 평균 자기 신뢰도는 4.67점이지만 반복 일치도는 낮아 신뢰도 보정도 실패했다.

따라서 현재 Gemini Flash-Lite 결과는 transcript 누락을 보완하는 멀티모달 진단 자료로 사용하고, 검증된 주 Judge로 채택하지 않는다. 자동 모델 중 반복 신뢰도 게이트를 통과한 것은 Terra뿐이며, 최종 타당성 판단은 아직 비어 있는 3인 인간 블라인드 평가 54행을 완료한 뒤 내린다.

## 동일 모델 모달리티 A/B

모델 차이와 멀티모달 효과를 분리하기 위해 Gemini 3.1 Flash-Lite에 같은 18쌍을 같은 배치·반복 조건으로 다시 입력했다. A는 장면 설명과 transcript만, B는 같은 텍스트와 실제 영상·음성을 사용했다.

- 편집 반복 일치도: A 0.6667 → B 0.5000
- 성과 반복 일치도: A 0.5556 → B 0.6111
- Pos 엄격 정확도: A 0.1667 → B 0.3889
- 결정된 비교의 Pos 정확도: A 0.3000 → B 0.6364
- 총 토큰: A 88,606 → B 486,560

멀티모달은 성과 잠재력 정합성을 높였지만 편집 판단의 반복 안정성과 비용은 악화했다. 자세한 결과는 `reports/gemini_multimodal_ablation_2026-07-21.md`에 기록했다.

## 실행

아마존에 API 키를 등록한다.

```bash
echo 'export GEMINI_API_KEY="YOUR_KEY"' >> ~/.bashrc
source ~/.bashrc
```

먼저 1쌍만 2회 테스트한다.

```bash
cd ~/vpick
python3 src/run_gemini_multimodal_batch_judge.py \
  --pairs results/gold_pairwise_judge_v4/input/pairwise_candidates_blind.jsonl \
  --candidates data/processed/gold_judge_v1/input/candidates_blind.csv \
  --config config/gold_pairwise_judge_v5_multimodal_batch.json \
  --out-dir results/gold_pairwise_judge_v5_multimodal_batch/scores \
  --repeat-count 2 --batch-size 1 --max-comparisons 1
```

정상 동작하면 전체 18쌍을 실행한다.

```bash
REPEAT_COUNT=2 WORKERS=1 RETRIES=0 REQUEST_INTERVAL_SEC=65 \
  bash scripts/run_gold_pairwise_gemini_multimodal_batch_v5.sh
```

실제 결과는 `results/gold_pairwise_judge_v5_multimodal_batch/`에 저장된다. dry-run 행은 평가기가 자동 제외한다.
