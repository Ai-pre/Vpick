# Gold Pointwise LLM-as-a-Judge 평가체계 v4

## 평가 질문

고정된 하나의 Gold 숏폼 구간이 다른 후보와 무관하게 어느 정도의 편집 품질과 내재적 성과 잠재력을 가지는가?

이 문서의 pointwise 절대평가가 메인 평가체계다. 쌍대평가는 모델의 위치 편향이나 최종 Vpick-Ours 대응 비교를 확인하는 보조 실험으로만 사용한다.

## 데이터

- 실제 게시 숏폼에서 원본 구간을 확인한 Gold: 45개
- Pos: 31개
- Neg: 9개
- Unlabeled: 5개
- 채널: 6개
- 반복 평가: 후보당 2회

모든 45개는 Gold 구간이다. Pos/Neg는 Gold 여부가 아니라 같은 채널 내 게시 성과 백분위에 따른 외부 성과 라벨이다.

## 블라인드 입력

Judge 입력:

- 익명 candidate ID
- 고정된 시작·종료 시각과 길이
- 장르와 언어
- Vpick 장면 설명
- 후보 내부 transcript
- 경계 확인용 before/after context
- Gemini 실행에서는 같은 YouTube 영상 구간의 화면과 음성

Judge 입력에서 제외:

- Pos/Neg/Unlabeled
- 조회수와 좋아요
- 채널명과 채널 내 백분위
- Gold pair ID
- 다른 후보의 점수나 순위

## 평가 축

### 편집 구간 품질

- 상황·논점 명확성 15%
- 사건·대화·주장 진행성 15%
- setup-payoff·결론 완결성 25%
- 시작·종료 경계 자연스러움 20%
- 콘텐츠 밀도 15%
- 독립 이해 가능성 10%

### 내재적 성과 잠재력

- 감정·반응 강도 20%
- 갈등·반전·발견·변화 20%
- 구체성·새로움 20%
- 공감·논쟁·공유 가능성 15%
- payoff 강도 15%
- 훅·제목화 가능성 10%

각 세부 항목은 1~5점이며 가중합을 0~100점으로 환산한다. 근거가 부족하면 낮은 점수를 추측하지 않고 `abstain`한다.

## 모델 조건

### Terra transcript-only

- 모델: GPT-5.6 Terra
- 한 API 요청에 후보 1개
- 실제 영상 없이 장면 설명·transcript만 사용
- 총 45개 x 2회 = 90요청

### Gemini multimodal

- 모델: Gemini 3.1 Flash-Lite
- 실제 YouTube 영상·음성 2 FPS
- 무료 요청 한도 때문에 요청당 5개 후보를 전달하되 각 후보를 독립 절대평가하도록 지시
- 반복마다 후보 순서와 배치 구성을 변경
- 총 45개 x 2회 = 90판정, 18요청

Gemini는 후보를 쌍으로 비교하지 않지만 한 요청에 여러 후보가 있어 배치 앵커링 가능성이 남는다. 이 한계는 반복 안정성에 포함해 진단한다.

## 검증 지표

Judge 신뢰성:

- 후보 평가 커버리지 >= 0.80
- 편집 점수 반복 Spearman >= 0.80
- 성과 점수 반복 Spearman >= 0.80
- 층화 표본 15개에 대한 3인 인간 절대평가 완성률 = 1.00
- 편집·성과 모델-인간 Spearman >= 0.70

외부 성과 정합성 진단:

- Pos와 Neg의 평균·중앙값 차이
- Pos>Neg AUC
- 조회수·좋아요·좋아요율·채널 내 백분위와 성과 점수의 Spearman 상관
- 채널별 Pos>Neg AUC

Pos>Neg AUC는 Judge 타당성의 정답이 아니다. 게시 성과에는 제목·썸네일·채널 노출·업로드 시점이 섞여 있으므로 인간 콘텐츠 평가와 분리해 보고한다.

## 실제 결과

| 지표 | Terra transcript-only | Gemini multimodal |
|---|---:|---:|
| 후보 커버리지 | 0.9778 | 0.9778 |
| 편집 반복 Spearman | 0.8263 | 0.3617 |
| 성과 반복 Spearman | 0.7968 | 0.5172 |
| 편집 반복 MAE | 6.6193 | 11.5244 |
| 성과 반복 MAE | 5.6818 | 9.4207 |
| Pos 평균 성과 점수 | 47.6250 | 60.2708 |
| Neg 평균 성과 점수 | 44.9306 | 55.2778 |
| Pos>Neg AUC | 0.5500 | 0.6333 |
| 채널 백분위 상관 | 0.0361 | 0.1788 |
| 평균 자기 신뢰도 | 3.7222 | 4.1111 |

Terra는 편집 반복 기준을 통과했지만 성과 반복 상관이 0.7968로 기준 0.80에 근소하게 미달했다. Gemini는 외부 성과 정합성이 더 높았지만 두 반복 신뢰도 기준을 모두 통과하지 못했다.

Gemini의 편집 세부 점수 중 4점 이상 비율은 60.2%로 Terra 29.7%보다 높았고, 평균 편집 점수도 65.68 대 45.24였다. 영상 입력이 점수 포화와 과신을 함께 키운 것으로 보인다.

두 모델의 후보 평균점수 상관은 편집 0.6712, 성과 0.6197이었다. 완전히 반대되는 Judge는 아니지만 동일한 기준을 안정적으로 재현한다고 보기에는 부족하다.

## 현재 판정

- Terra: 가장 안정적인 주 Judge 후보지만 인간 검증 전까지 미확정
- Gemini: 성과 잠재력 보조 진단이며 주 Judge로 사용하지 않음
- 최종 상태: `pending_human_scores`

다음 단계는 채널과 성과 라벨을 층화해 뽑은 대표 15개를 3명이 평가하는 것이다. 총 45행이며 한 사람은 영상 15개만 본다. 이 표본에서 각 모델과 인간 평균점수의 Spearman 상관을 계산한다. 전체 45개 인간 평가는 프로젝트 필수 범위로 두지 않는다.

## 실행

```bash
cd ~/vpick
REPEAT_COUNT=2 RUN_TERRA=1 RUN_GEMINI=1 bash scripts/run_gold_pointwise_judge_v4.sh
```

결과는 `results/gold_pointwise_judge_v4/`에 저장된다.
