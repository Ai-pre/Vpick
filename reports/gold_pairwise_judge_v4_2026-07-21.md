# Gold Pairwise Judge v4 실험 결과

## 구성

- Gold 45개 중 성과 라벨이 확정된 Pos 31개와 Neg 9개 사용
- Pos와 Neg가 함께 존재하는 3개 채널 사용
- Neg 9개당 같은 채널 Pos 2개를 매칭해 총 18개 비교
- 후보당 Terra와 Claude 각 2회 평가
- 두 번째 반복은 좌우 순서를 뒤집어 위치 편향 측정
- 총 실제 LLM 판단 72건

Terra는 좌우 반전에도 87.5% 동일한 판단을 내려 반복 신뢰도 기준을 통과했다. Claude는 성과 잠재력 반복 일치도가 76.5%로 기준 80%를 넘지 못했다.

반면 두 모델 모두 조회 성과 Pos를 안정적으로 선택하지 못했다. Pilot에서는 조회수 상위 구간의 대사가 심하게 깨졌거나 실제 시각적 payoff가 텍스트에 나타나지 않았고, 일부 조회수 하위 구간은 텍스트상 주제와 완결성이 더 명확했다.

## 결론

1. Terra를 인간 블라인드 검증 대상 1차 Judge로 선택한다.
2. Claude는 단독 Judge가 아니라 불일치 사례를 찾는 보조 모델로 사용한다.
3. Pos/Neg 조회 성과는 콘텐츠 품질의 정답이 아니라 외부 성과 정합성 지표로 유지한다.
4. 최종 콘텐츠 Judge 유효성은 3인 인간 평가와의 일치율로 결정한다.
5. 현재 상태는 `pending_human_labels`이며 인간 평가 전에는 validated라고 발표하지 않는다.

평가 코드·쌍대비교 데이터·모델 결과·인간 입력 시트까지 구축됐으며, 남은 외부 작업은 세 명의 독립 평가자가 빈 라벨을 입력하는 것이다.
