# Codex Shortform Judge v10 블라인드 평가 결과

## 1. 평가 목적

후보별 숏폼 설명, 최종 자막, Vpick 원본 영상 개요와 후보 전후 문맥만 사용하여 60개 후보를 독립적인 pointwise 방식으로 평가했다.

채점이 끝날 때까지 채널명, 조회수, 좋아요 수, 채널 내 성과 백분위, 숏폼 URL을 보지 않았다. `Pos/Neg` 이진 라벨은 평가 기준과 점수 산출에 사용하지 않았으며, 현재 검증의 주지표로도 사용하지 않는다.

점수를 확정한 뒤 비공개 성과표를 결합하여 Judge 점수와 **채널 내 연속형 성과 백분위**가 얼마나 일치하는지 검증했다.

## 2. 평가 방식

- 프롬프트: `prompts/shortform_judge_v10_ko.md`
- 평가 후보: 60개
- 평가 방식: 후보 1개씩 독립 채점
- 입력: 후보 구간 설명, 자막, 원본 영상 개요, 직전·직후 장면 문맥
- 편집 품질: 원본 내 중요도, 독립적 이해 가능성, 전개와 회수, 시작·종료 경계
- 콘텐츠 흡인력: 초반 주목도, 변화 또는 발전, 감정·정보 이득, 기억에 남는 구체성
- 총점: 편집 품질 50% + 콘텐츠 흡인력 50%
- 근거 충실도: `confidence`, `failure_flags`로 별도 기록하고 총점에는 합산하지 않음
- 결과: 60개 채점, `abstain` 0개

## 3. 블라인드 점수 분포

- 평균: 75.9375점
- 최솟값: 21.875점
- 최댓값: 100점
- 고유 점수: 18개
- 가장 큰 동점 집단: 7개

8개 세부 항목을 고정식으로 합산하여, 과거의 단일 1~5점 척도보다 순위 해상도를 높였다.

## 4. 연속형 성과 타당도

성과는 절대 조회수가 아니라 각 후보가 **같은 채널의 다른 숏폼 대비 어느 위치에 있는지**를 나타내는 채널 내 성과 백분위로 정규화했다. Judge의 `engagement_score_100`과 이 연속형 백분위 사이의 순위 상관을 측정했다.

| 지표 | 결과 |
|---|---:|
| 평가 후보 | 60 |
| 검증 채널 | 6 |
| 채널 중심화 성과와의 상관 | 0.0717 |
| 6개 채널 macro Spearman | 0.1089 |
| 표본이 비교적 안정적인 4개 채널 macro Spearman | 0.1384 |

현재 Judge 점수는 채널 내 실제 성과 순서를 유의미하게 복원하지 못했다. 따라서 v10은 평가 항목과 출력 규격을 고정한 **평가 체계 구현본**으로는 쓸 수 있지만, 신규 숏폼의 성과를 예측하는 Judge로 확정하기에는 근거가 부족하다.

이 불일치는 단순한 프롬프트 오류로만 단정할 수 없다. 실제 성과에는 제목, 썸네일, 출연자 인지도, 업로드 시점, 알고리즘 노출이 함께 작용한다. 반면 현재 입력은 후보 자막과 Vpick 분석 정보에 집중되어 있어 시각 연출, 음성 톤, 자막 편집과 게시 조건이 제한적으로만 반영된다.

## 7. 결론

v10은 60개 후보를 같은 기준으로 독립 채점하고, 편집 품질과 콘텐츠 흡인력을 분리해 설명 가능한 점수를 만드는 데 성공했다.

그러나 채널 내 연속형 성과 백분위와의 상관은 낮았다. 현재 결과는 다음과 같이 표현하는 것이 정확하다.

> 원본 문맥을 포함한 pointwise LLM-as-a-Judge 평가 체계는 구축했지만, 실제 채널 내 성과 순위를 예측하는 타당도는 아직 확보하지 못했다.

후속 실험에서는 평가 항목이나 가중치를 결과를 본 뒤 임의로 바꾸지 않고, 사전에 정한 후보식을 별도 검증 세트에서 비교해야 한다. 또한 제목·썸네일·시각·음성 정보를 추가한 입력이 성과 정합성을 실제로 높이는지 분리 실험이 필요하다.
