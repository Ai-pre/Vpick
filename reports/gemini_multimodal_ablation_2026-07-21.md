# Gemini 멀티모달 A/B 실험 보고

## 실험 질문

같은 Gemini 모델에 영상·음성을 추가하면 장면 설명과 transcript만 입력했을 때보다 Gold Pos-Neg 숏폼 쌍대비교가 개선되는가?

## 통제 조건

- 모델: Gemini 3.1 Flash-Lite
- 데이터: 같은 채널의 Pos-Neg Gold 18쌍
- 반복: 각 비교 2회, 2회차 LEFT/RIGHT 반전
- 공통 조건: 평가 루브릭, 익명 candidate ID, 장면 설명, transcript, before/after context, 배치 크기 4, temperature 0, 구조화 JSON 스키마
- A: 장면 설명 + transcript만 입력
- B: A의 입력 + 실제 YouTube 구간 영상·음성(2 FPS)
- 블라인드: Pos/Neg, 조회수, 좋아요, 채널명, 성과 백분위는 모델에 전달하지 않음

B에는 실제 영상을 우선 근거로 사용하라는 모달리티 지시만 추가했다. 따라서 모델과 평가 기준은 같지만 프롬프트 문자열이 완전히 동일한 실험은 아니다.

|---|---:|---:|---:|
| 평가 커버리지 | 1.0000 | 1.0000 | 동일 |
| 편집 판단 반복 일치도 | 0.6667 | 0.5000 | -0.1667 |
| 성과 판단 반복 일치도 | 0.5556 | 0.6111 | +0.0555 |
| Pos 엄격 선호 정확도 | 0.1667 | 0.3889 | +0.2222 |
| 결정된 비교의 Pos 정확도 | 0.3000 | 0.6364 | +0.3364 |
| 평균 자기 신뢰도(5점) | 4.1111 | 4.6667 | +0.5556 |
| 반복 신뢰도 게이트 | 실패 | 실패 | 동일 |

성과 판단 결과는 다음처럼 이동했다.

| A → B | 비교 수 |
|---|---:|
| 정답 → 정답 | 3 |
| 오답 → 오답 | 4 |
| 불안정 → 정답 | 4 |
| 오답 → 불안정 | 3 |
| 불안정 → 불안정 | 4 |
| 정답 → 오답 | 0 |

즉 transcript-only의 `정답 3 / 오답 7 / 불안정 8`이 멀티모달에서 `정답 7 / 오답 4 / 불안정 7`로 개선됐다. 두 모달리티가 모두 반복상 결정적이었던 비교에서는 편집 8쌍과 성과 7쌍의 선택 방향이 전부 같았고 정면으로 반대 선택한 비교는 없었다.

## 채널별 성과 정합성

| 채널 | A: transcript-only | B: multimodal |
|---|---:|---:|
| 숏박스 | 0.0000 | 0.3333 |
| Pilot 채널 | 0.0000 | 0.0000 |
| 워크맨 | 0.3750 | 0.6250 |

멀티모달 개선은 숏박스와 워크맨에서 나타났지만 Pilot 채널에서는 나타나지 않았다. 3개 채널, 18쌍의 작은 표본이므로 장르 전반으로 일반화할 수 없다.

## 안정성·보정 진단

- transcript-only의 좌우 반전 일치 쌍: 편집 12/18, 성과 10/18
- multimodal의 좌우 반전 일치 쌍: 편집 9/18, 성과 11/18
- 같은 화면 위치를 두 번 고른 위치 고정 사례: A 편집 3쌍·성과 5쌍, B 편집 4쌍·성과 5쌍
- A의 편집 세부 점수 중 4점 이상 비율: LEFT 58.8%, RIGHT 42.1%
- B의 편집 세부 점수 중 4점 이상 비율: LEFT 83.3%, RIGHT 83.3%
- A의 좌우 편집 총점 평균: 61.53, 56.63
- B의 좌우 편집 총점 평균: 84.76, 84.44

영상 입력은 성과 신호를 추가했지만 편집 점수를 전반적으로 높여 점수 포화를 만들었고, 높은 자기 신뢰도도 실제 반복 안정성을 반영하지 못했다.

## 결론

현재 표본에서 멀티모달은 transcript-only보다 **내재적 성과 잠재력 판별에는 유용했다**. 특히 불완전한 transcript만으로 결정하지 못한 4쌍을 Pos 방향으로 올바르게 구분했고, 기존 정답을 오답으로 뒤집은 사례는 없었다.

반면 **편집 구간 품질 Judge로는 개선되지 않았다**. 경계와 완결성을 실제로 볼 수 있음에도 좌우 반전 반복 일치도가 하락했고 점수 포화도 커졌다. 따라서 현재 권장안은 transcript-only를 버리는 것이 아니라 다음처럼 역할을 나누는 것이다.

```text
transcript-only Judge: 편집 구조의 1차 안정성 점검
multimodal Judge: 표정·행동·억양·화면 자막이 필요한 성과 잠재력 보조 판단
두 Judge 불일치 또는 반복 불안정: 인간 평가로 전달
```

이 결론은 아직 인간 정답과 직접 비교하지 않은 중간 결론이다. 18쌍 x 3명의 블라인드 인간 평가가 완료된 뒤 인간 다수결 일치도로 최종 채택 여부를 결정해야 한다.
