# mR3 GPU0 전수 평가 결과

## 실험 목적

동일한 60개 숏폼 후보를 대상으로 mR3가 v7 평가 기준을 안정적으로
수행하는지 확인하고, 자막만 제공한 경우와 Vpick 장면 설명을 함께 제공한
경우를 비교했다.

## 실행 조건

- 모델: `rubricreward/mR3-Qwen3-8B-tgt-prompt-en-thinking`
- 장치: Amazon 서버 GPU0, Quadro RTX 8000 48GB
- 정밀도: BF16
- 평가 기준: `shortform_reference_judge_v7_ko`
- 생성: 비샘플링, seed `20260724`, 최대 1,024토큰
- 출력 모드: non-thinking 직접 JSON
- 후보 수: 입력별 60개, 총 120회
- 형식 재시도: 0건
- abstain: 입력별 0건

공식 thinking 모드 파일럿은 2,048토큰을 사고 과정에 모두 사용해 최종
JSON 전에 잘렸다. 전수 평가는 같은 모델과 평가 기준을 유지하되,
구조화 출력을 안정적으로 얻기 위해 non-thinking 모드로 수행했다.

## 결과

| 지표 | 자막 전용 | Vpick 설명+자막 |
|---|---:|---:|
| 유효 평가 | 60/60 | 60/60 |
| 체크리스트 평균(100점) | 8.5714 | 40.8333 |
| 중요도 평균(1~5점) | 2.0333 | 2.6167 |
| 숏폼 적합 판정률 | 13.33% | 66.67% |
| pooled AUC | 0.4889 | 0.4844 |
| 채널별 macro AUC | 0.5010 | 0.5042 |
| 안정 채널 macro AUC | 0.5015 | 0.4126 |
| 채널 내 중심화 상관 | 0.0024 | 0.0168 |

여기서 성과 라벨은 절대적인 좋은/나쁜 콘텐츠가 아니라 같은 채널 내
상대적 고성과/저성과 신호다.

## 입력 간 비교

- 공통 후보 ID: 60/60 일치
- Vpick 입력의 체크리스트 평균 증가: `+32.2619`
- Vpick 점수가 더 높은 후보: 41개
- 동일한 후보: 12개
- Vpick 점수가 더 낮은 후보: 7개
- 체크리스트 점수 Spearman: `-0.1718`
- 중요도 점수 Spearman: `-0.0267`
- 중요도 점수 완전 일치율: `36.67%`

## 결론

mR3는 Vpick 설명이 추가되면 숏폼 적합성과 체크리스트 점수를 크게
높였지만, 실제 채널 내 상대 성과와의 정렬은 두 입력 모두 무작위 수준에
가까웠다. 또한 동일 후보에 대한 두 입력 방식의 점수 일관성도 낮았다.

따라서 이번 설정의 mR3를 단독 성과 예측 Judge로 채택하지 않는다.
Vpick 설명의 영향도를 확인하는 보조 비교 실험으로는 유효하지만,
현재 평가체계의 주 Judge를 대체할 근거는 확보하지 못했다. thinking
모드 자체의 성능은 이번 전수 결과와 분리해 해석해야 한다.
