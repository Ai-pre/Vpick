# Gold Judge v3 멀티모델 비교 보고서

## 1. 실험 목적

동일한 Gold 구간과 동일한 평가 프롬프트를 여러 LLM에 적용해, 모델에 따라 평가 결과가 얼마나 달라지는지 확인했다. 이번 실험은 Ours 후보 선택 파이프라인의 성능 비교가 아니라, 조회 성과가 높은 Pos와 낮은 Neg를 LLM-as-a-Judge 점수가 구분할 수 있는지 검증하는 평가체계 실험이다.

## 2. 실험 조건

- 입력: Gold 구간 45개
- 확정 성과 라벨: Pos 27개, Neg 7개, 미분류 11개
- 프롬프트: `shortform_candidate_judge_v3_ko`
- 반복 평가: 후보당 2회
- 평가 기준: 오프닝, 독립 이해 가능성, 완결성, 몰입 가치, 경계 자연스러움, 제목화 가능성
- 근거 품질: 장면 설명 지지도, 대사 인식 가능성, 시작·끝 관찰 가능성
- 판단 불가능한 경우: 억지로 낮은 점수를 주지 않고 `abstain` 처리

## 3. 결과

| 모델 | 후보 커버리지 | 반복 Spearman | Pos 평균 | Neg 평균 | 평균 차이 | Pos>Neg AUC |
|---|---:|---:|---:|---:|---:|---:|
| GPT-5.6 Terra | 100.0% | 0.7802 | 53.94 | 47.68 | +6.26 | 0.6402 |
| Claude Sonnet 5 | 86.7% | 0.8059 | 46.56 | 49.38 | -2.81 | 0.4132 |
| GPT-4o-mini | 88.9% | 계산 불가 | 50.00 | 50.00 | 0.00 | 0.5000 |
| Gemini 3.5 Flash | 실행 대기 | 실행 대기 | 실행 대기 | 실행 대기 | 실행 대기 | 실행 대기 |

`GPT-4o-mini`는 점수를 부여한 80회 중 79회를 50점으로 출력해 분산이 사라졌다. 따라서 반복 순위상관을 계산할 수 없으며 v3 프롬프트와의 조합은 사용하기 어렵다.

`Claude Sonnet 5`는 판단 보류 기능을 가장 적극적으로 사용했고 반복 안정성은 기준치 0.8을 넘겼다. 그러나 Pos와 Neg의 점수 방향이 역전되어 단독 성과 판별 모델로는 부적합했다.

`GPT-5.6 Terra`는 모든 후보를 평가했고 세 모델 중 유일하게 Pos 평균이 Neg 평균보다 높았다. 다만 반복 Spearman이 목표값 0.8에 조금 못 미쳤고, 기존 GPT-4o-mini v2의 Pos/Neg AUC 0.6667보다 높지는 않았다.

## 4. ASR 저품질 구간 확인

대사가 심하게 깨진 고성과 파일럿 구간 `P010`, `P011`을 확인했다.

- Claude Sonnet 5: 두 구간 모두 판단 보류
- GPT-4o-mini: `P010`은 50점, `P011`은 판단 보류
- GPT-5.6 Terra: 각각 37.5점, 31.25점

v3의 판단 보류 규칙은 ASR 오류를 곧바로 영상 품질 0점으로 오인하는 문제는 줄였다. 그러나 텍스트와 장면 설명만으로는 실제 편집, 표정, 자막, 음향 효과를 관찰할 수 없으므로 고성과 구간을 높은 점수로 복구하지는 못했다.

## 5. 결론

현재 v3 평가체계의 1차 모델 후보는 `GPT-5.6 Terra`다. 단, 이번 결과만으로 평가체계가 검증됐다고 볼 수는 없다. Claude와의 상관도는 0.6558에 그쳤고, 성과 라벨과의 관계도 강하지 않다.

다음 검증에서는 모델을 다시 프롬프트에 맞추는 방식으로 튜닝하기 전에 사람이 동일 구간을 블라인드 평가해야 한다. 인간 평가와 일치하는 모델·기준을 선택해야 하며, 조회수 라벨과 LLM 점수의 불일치는 콘텐츠 품질과 노출 성과가 같은 개념이 아니라는 증거일 수도 있다.

## 6. Gemini 실행

Gemini 호출 코드는 구현돼 있다. Amazon 환경에 `GEMINI_API_KEY`를 등록한 뒤 아래 명령으로 네 모델을 같은 조건에서 다시 실행한다.

```bash
echo 'export GEMINI_API_KEY="YOUR_KEY"' >> ~/.bashrc
source ~/.bashrc
cd ~/vpick
REPEAT_COUNT=2 bash scripts/run_gold_judge_v3_comparison.sh
```

Gemini 결과가 생성되면 `data/processed/gold_judge_v3_comparison/validation/`에 동일한 검증 지표가 추가된다.

## 7. Pilot 성과 라벨 갱신

2026-07-21에 Pilot 11개가 속한 채널의 Shorts 50개 코호트를 다시 수집해 조회수 중간순위 백분위를 계산했다. 상위 25%는 Pos, 하위 25%는 Neg, 중간 50%는 Unlabeled로 분류한 결과 Pilot은 Pos 4개, Neg 2개, Unlabeled 5개가 됐다. 전체 Gold 분포는 Pos 31개, Neg 9개, Unlabeled 5개다.

갱신된 라벨로 기존 점수를 다시 평가한 결과는 다음과 같다.

| 모델 | Pos 평균 | Neg 평균 | 평균 차이 | Pos>Neg AUC |
|---|---:|---:|---:|---:|
| GPT-5.6 Terra v3 | 51.21 | 49.58 | +1.63 | 0.5466 |
| Claude Sonnet 5 v3 | 45.29 | 49.38 | -4.09 | 0.4038 |
| GPT-4o-mini v3 | 50.00 | 50.00 | 0.00 | 0.5000 |
| GPT-4o-mini v2 | 46.57 | 40.42 | +6.16 | 0.5789 |

Pilot을 포함하면 모든 모델의 Pos/Neg 분리력이 약해졌다. 이는 새 데이터가 단순한 추가 표본이 아니라, 텍스트 기반 Judge가 실제 Shorts 성과를 충분히 설명하지 못하는 사례를 포함한다는 뜻이다.
