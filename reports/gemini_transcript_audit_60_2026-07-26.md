# 60개 후보 자막 교차검증 및 최종화

## 목적

Vpick 장면 API 또는 yt-dlp fallback으로 수집한 60개 후보 자막을
Gemini의 YouTube 영상 이해 결과와 비교하여, 누락ㆍ오인식 자막을
보완하되 Gemini 결과를 무조건 정답으로 사용하지 않는 것을 원칙으로 했다.

## 검증 절차

1. 기존 60개 자막의 공백, 발화량, 구간 커버리지, 타임스탬프 범위를 검사했다.
2. 구조적으로 불완전한 2개를 Gemini 롱폼 구간과 쇼츠 양쪽에서 먼저 복구했다.
3. 60개 쇼츠 전체를 Gemini로 독립 전사하여 기존 원본 구간 자막과 비교했다.
4. 문자열 순서 유사도와 문자 bigram 포함도를 함께 사용해 불일치를 탐지했다.
5. 자동 불일치 2개와 유사도 0.5 미만 경계 후보 8개를 Gemini가 롱폼에서
   다시 전사하도록 했다.
6. 최종 선택에서는 문장 정확도뿐 아니라 원본 절대 타임스탬프와 주변 문맥의
   보존 여부를 함께 판단했다.

## 사용 데이터와 모델

- 최종 후보: 60개
- 원 자막 제공자: Vpick 장면 API 47개, yt-dlp fallback 13개
- Gemini 쇼츠 전사: 60개 모두 성공
- 모델별 처리 수: `gemini-3.6-flash` 20개,
  `gemini-3.5-flash` 20개, `gemini-3-flash-preview` 20개
- Gemini 자체 신뢰도: 중앙값 0.98, 최솟값 0.90

무료 티어의 모델별 요청 한도 때문에 세 Flash 모델로 나누었지만, 모든 모델에
동일한 JSON 스키마와 동일한 전사 규칙을 적용했다. 모델명은 후보별 비교 파일에
보존했다.

## 소스별 비교 결과

| 기존 자막 제공자 | 후보 수 | 순서 유사도 중앙값 | 포함도 중앙값 | 롱폼 재검증 |
|---|---:|---:|---:|---:|
| Vpick 장면 API | 47 | 0.653 | 0.700 | 8 |
| yt-dlp fallback | 13 | 0.675 | 0.691 | 2 |

자동 임계값에서는 Vpick 자막 47개가 모두 허용 범위였지만, 유사도 0.5
미만인 경계 후보를 직접 검토하자 사투리, 혼합 언어, 고유 표현, 누락 발화가
깨진 8개가 확인됐다. yt-dlp fallback은 13개 중 11개를 그대로 사용할 수
있었고, 혼합 언어와 구어체가 포함된 피식대학 후보 2개를 보정했다.

## 최종 결정

- 49개: 기존 Vpick/yt-dlp 자막 유지
  - Gemini와 내용이 교차검증되었다.
  - 기존 자막이 롱폼 절대 시간과 앞뒤 문맥을 보존하므로 데이터셋 입력으로
    더 적합하다.
- 2개: 앞선 Gemini 결손 복구본 유지 및 재검증
  - `C_519202486aef76`, `C_4479c41b6aa80d`
- 6개: Gemini 쇼츠 발화 사용
  - 쇼츠 전사가 더 선명했고, 별도 Gemini 롱폼 전사로 같은 원본 구간의
    발화임을 재확인했다.
  - 세부 시각은 버리고 매니페스트의 원본 시작ㆍ종료 구간만 유지했다.
- 2개: 쇼츠ㆍ롱폼ㆍ기존 자막을 보수적으로 조정
  - `C_87c2f9c2d22522`, `C_c3f86bdf30fa21`
  - 혼합 언어와 구어체 때문에 단일 전사만으로 확정하지 않았다.
- 1개: Gemini 롱폼 전사 사용
  - `C_f9645ed47107f3`
  - 발화뿐 아니라 반환된 세부 시각도 매니페스트 구간과 일치했다.

롱폼 재검증 대상 10개는 Vpick 장면 API 8개, yt-dlp fallback 2개였다.
Gemini가 제시한 세부 절대 시각은 영상에 따라 크게 밀리는 현상이 있어,
시간축이 실제 매니페스트 범위와 일치한 한 건을 제외하고 사용하지 않았다.

전체 감사 전에 구조적으로 불완전했던 `C_519202486aef76`과
`C_4479c41b6aa80d`도 Gemini 롱폼ㆍ쇼츠 이중 확인으로 복구했다. 전자는
`[음악][박수]`만 있던 자막에서 실제 대화를 복원했고, 후자는 77초 구간 중
약 12초만 있던 발화를 확장했다.

## 품질 결론

Gemini는 무자막ㆍ저밀도ㆍ사투리ㆍ혼합 언어 후보의 **발화 복구**에는
Vpick/yt-dlp보다 유리했다. 반면 원본 롱폼의 **절대 타임스탬프와 주변
문맥**은 Vpick 또는 yt-dlp 기반 자료가 더 안정적이었다. 따라서 최종
데이터는 Vpick을 기본으로, yt-dlp를 보완으로, Gemini를 전량 교차검증 및
경계 후보 발화 복구에 사용하는 다중 증거 방식으로 확정했다.
