# Gold-only LLM-as-a-Judge v1 결과

## 목적

개선 파이프라인이나 Ours/Vpick 후보를 평가하기 전에, GPT Judge 자체가 외부 성과가 높은 게시 숏폼과 낮은 게시 숏폼을 구분하는지 검증한다. 모든 입력 구간은 실제 게시 숏폼과 연결된 Gold이며, `Pos`와 `Neg`는 Gold 여부가 아니라 성과 라벨이다.

## 데이터와 누출 방지

- 전체 Gold: 45개
- Pos: 27개
- Neg: 7개
- 미분류 Pilot: 11개
- 조회수와 좋아요가 모두 있는 Gold: 35개
- Judge 입력: 고정된 원본 구간의 Vpick 장면 설명, 대사, 앞뒤 문맥
- 비공개 정보: Pos/Neg, 조회수, 좋아요, 숏폼 ID, 데이터 출처
- Ours/Vpick 후보: 사용하지 않음

## 실행 조건

- 모델: GPT-4o mini
- temperature: 0
- 후보별 독립 호출: 1개씩
- 반복: 2회
- 채점 행: 90개(45개 x 2회)
- 점수: 6개 항목의 가중 합산, 100점 만점

## 결과

| 지표 | 결과 |
|---|---:|
| 반복 평가 Spearman | 0.9655 |
| Pos 평균 | 48.8426 |
| Neg 평균 | 36.7857 |
| 평균 차이 | 12.0569 |
| Pos > Neg AUC | 0.6667 |
| 조회수 Spearman | 0.1357 |
| 좋아요 Spearman | 0.0724 |

GPT Judge는 반복 안정성이 높았고 Pos에 Neg보다 평균 12.06점 높은 점수를 부여했다. 그러나 Neg가 7개뿐이고 조회수·좋아요와의 연속 순위 상관은 약하다. 현재 결과는 성과 집단을 구분하는 경향을 확인한 단계이며, 평가체계가 검증 완료되었다고 판단하지 않는다.
