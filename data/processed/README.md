# Processed Data Policy

공개 저장소에는 과거 60개 개발 CSV, 채널명 정규화 맵, 입력 템플릿과
공개 가능한 예시를 둡니다. 과거 CSV는 실험 이력 보존용이며 최종 94개
평가 패키지와 동일하지 않습니다.

94개 최종 데이터셋의 후보별 Gold 타임스탬프, 성과 라벨과 조회수는
`data/private/`에서 별도로 관리하며 Git에 포함하지 않습니다. Vpick raw scene
결과는 `data/raw/`에 두고 역시 Git에서 제외합니다.

최종 데이터 현황:

- 채널 6개
- 고유 롱폼 85개
- 실제 공개 숏폼 94개
- HIGH 30개
- MID 34개
- LOW 30개

공개 입력 형식은 `data/templates/`를 참고하십시오.
